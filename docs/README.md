# كتيّب مُراح — دليل الاستخدام

تطبيق **مراح** لإدارة الحلال تطبيقٌ **محلّي بالكامل**: بياناتك على جهازك، بلا إنترنت ولا حساب ولا تسجيل دخول.

## الكتيّب

- **[🐑 دليل أصحاب الحلال](دليل-أصحاب-الحلال.md)**
  إدارة الحلال كاملةً: التنقّل (🏠 الرئيسية / 🐑 الحلال / ♀️ الإناث / 🐏 الفحول / 👶 المواليد + ☰ الإعدادات / ⋮ الأدوات ببحث فوري)، الحلال وسجل البهيمة بتبويباته (النسب/الإنجاب/المرضي/العلاجات/التطعيمات)، تعدّد المواليد، التلقيح والحمل والإجهاض، فحول المراح (بأبنائهم وبناتهم)، حظائر رئيسية وفروع، دليل التواصل، التطعيمات والعلاجات (مع التعديل)، عمليات بالجملة، الميزانية، قفل التعديل للأمان، والنسخ الاحتياطي (بمجلد اختياري على الجهاز).

كل بند مكتوب بالصيغة: **العنوان كما في التطبيق · الفكرة · المختصر · التفصيل**.

## ملاحظات عامة

- **محلّي بالكامل:** قاعدة البيانات على الجهاز (IndexedDB)؛ لا يُرسَل شيء إلى أي خادم.
- **الخصوصية:** بياناتك خاصة بجوالك، ومحفوظة حتى عند تحديث التطبيق.
- **النسخ الاحتياطي:** خذ نسخة (تصدير JSON/CSV) بين الحين والآخر، خصوصاً قبل أي تغيير كبير.
