# مراح 🐪🐑🐐🐄 — تطبيق أندرويد (APK)

تطبيق أندرويد لإدارة الحلال (إبل، غنم، ماعز، بقر) — متابعة فردية من الولادة حتى البيع،
مع تطعيمات وعلاجات وتنبيهات. **محلّي بالكامل**: قاعدة البيانات على الجهاز (IndexedDB)،
يعمل **بدون إنترنت ولا خادم**، وبياناتك تبقى على جوالك فقط.

> **تطبيق أندرويد (APK) فقط.** الواجهة تُغلَّف عبر Capacitor وتُبنى بواسطة
> `npm run build:www` ثم Capacitor.

> **مستقل تماماً.** كل ملفاته داخل هذا المجلد ولا يعتمد على أي خادم أو خدمة سحابية.

## بناء تطبيق أندرويد (APK)
```bash
# 1) جهّز مجلد www/ (يُولَّد من index.local.html — لا يُدفَع لـ git)
APP_VERSION=1.0.0 npm run build:www

# 2) زامن Capacitor وابنِ الـ APK
npx cap sync android
cd android && ./gradlew assembleRelease   # أو استخدم GitHub Actions (android.yml)
```
> البناء آلي أيضاً عبر `.github/workflows/android.yml` الذي يُشغّل `npm run build:www`
> ثم يُنتج APK موقّعاً بمفتاح ثابت (يُثبَّت فوق القديم مع حفظ البيانات).

## البيانات
كل البيانات تُخزَّن محلياً على الجهاز عبر **IndexedDB** (`local-db.js`) — بلا خادم ولا
حساب ولا إنترنت. النسخ الاحتياطي والاستعادة عبر تصدير/استيراد JSON من داخل التطبيق.

## المزايا
- **سجل البهيمة:** النوع، رقم المراح، معرّف مرن (رقم/وسم/شريحة/اسم)، الجنس، الميلاد، اللون، الحالة، النسب، الملاحظات.
- **النسب التلقائي:** سجل الأم يعرض مواليدها.
- **التلقيح والحمل:** حساب مدة الحمل والولادة المتوقعة تلقائياً حسب النوع.
- **الولادات:** تسجيل المولود وربطه بالأم.
- **التطعيمات:** كتالوج أنواع (الاستخدام، الجرعة، العمر الموصى به، مدة الفاعلية، تحريم الحليب/اللحم) + إعطاء تطعيم مع حساب انتهاء التحريم واقتراح الجرعة القادمة.
- **العلاجات:** كتالوج أدوية + تسجيل علاج مع التحريم.
- **التنبيهات:** ولادة قريبة، انتهاء التحريم، مواعيد تطعيم.
- **النسخ الاحتياطي:** تصدير/استيراد JSON و CSV ومشاركة.
- **عربي RTL** بالكامل، وواجهة جوال بشريط سفلي.

## التقنية
HTML + CSS + JavaScript صِرف (بلا أطر عمل) مُغلَّف عبر **Capacitor** في تطبيق أندرويد.
قاعدة البيانات محلية عبر **IndexedDB**، و `tweetnacl` مُضمَّن للتحقّق من ترخيص التفعيل.
